# AI Patterns

## Quarkus MCP Example

https://github.com/davgordo/quarkus-mcp-example

"A clear, reproducible starting point" for experiments with Quarkus MCP over `streamable-http` transport and suitable open source models and language servers.

##  `agent-adventure`

Example showing a AI Agent powered text-based adventure game. Integrates user input from REST DSL, an AMQP queue for requests to the agent, and an Apache Came route with `langchain4j-agent` to call an LLM model.

## Camel Quarkus + Quarkus MCP

https://github.com/rh-ei-stp/demo-camel-quarkus-mcp

Demonstration of integrating an existing Camel Quarkus application with Quarkus MCP so that it can be invoked from new AI agents.
A pair of example AI agent application clients are provided: a Camel Quarkus application using the `langchain4j-agent` component and a 
Quarkus application with the `quarkus-langchain4j-mcp` extension.

## Camel Spring Boot + Spring AI MCP Server

https://github.com/rh-ei-stp/demo-camel-spring-boot-mcp

Demonstration of integrating an existing Camel Spring Boot application with Spring AI MCP Server so that it can be invoked from new AI agents.
An example AI agent application client is provided as a Camel Spring Boot application using the `langchain4j-agent` component.
